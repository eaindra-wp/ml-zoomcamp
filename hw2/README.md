# Homework 2 — Linear Regression

Homework for the regression module of the DataTalksClub Machine Learning Zoomcamp 2026.

## Topics

- Exploratory data analysis
- Handling missing values
- Train/validation/test splitting
- Linear regression from scratch with NumPy
- RMSE evaluation
- Regularization
- Testing model stability across random seeds
- Training on combined train and validation data

## Dataset

`car_fuel_efficiency_2026.csv`

The model predicts `fuel_efficiency_mpg` using vehicle characteristics such as engine displacement, horsepower, vehicle weight, and model year.

## Running

From the repository root:

```bash
uv run python hw2/hw2.py
```
